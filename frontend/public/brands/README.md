# Platform logos

The Creator studio shows a platform's official logo when its file is here, and a neutral badge otherwise:

| File | Get the official asset from |
|---|---|
| `youtube.svg` | YouTube Brand Resources |
| `instagram.svg` | Meta / Instagram Brand Resources |
| `tiktok.svg` | TikTok Brand Guidelines (TikTok for Developers) |

Download each logo from the platform's own brand site and follow its usage rules (clear space, no recoloring
or distortion). The logos are trademarks of their owners, which is why they are not bundled in this repo.
